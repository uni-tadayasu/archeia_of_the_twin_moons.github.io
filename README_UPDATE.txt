双月のアルケイア - 2026-11-07 キャラクター選択・全体バランス・詠唱時間 差分更新

【更新ファイルのみ】
index.html
main.js
data.js
game.js
field.js
mailbox.js

【適用】
最新版ゲームのルート（index.html と data.js がある階層）に上書き。
フォルダー構成は変更不要。既存の assets/ や server/ を削除しない。
変更を GitHub Pages に公開後、Chrome で Ctrl+Shift+R を押す。

【内容】
- FIGHTERS 230体すべてに、元GLBと対応する既存ポートレートを割り当て。
- 同一GLBを共有する派生キャラは同じ原画を使用。
  新規の顔画像は生成していません。
  任意の色相回転を無効化し、実モデルと無関係な衣装・肌の色変化を停止。
- 一般戦士・ボス・特別戦士・運営長専用の役割を保ち、体力、移動速度、
  基本攻撃、スキル、奥義のダメージや範囲を同じルールで再調整。
- すべての技は詠唱を終えてから発動。詠唱HUDに残り秒数と進捗を表示。
  一般技（目安0.35～1.85秒）、奥義（1.65～2.8秒）、秘奥義（2.55～3.6秒）。
  中断時は技の消費MP半分返還、奥義ゲージ35返還。
- ネットワークへの技発動通知は詠唱完了時に送信。再度詠唱しない。
- 最新の受信箱・運営長メール機能、氷鋼覇王ヴァルガルド、BGM、GLB、
  Cloudflare Workersの設定は変更していません。

【注意】
- 選択用画像は既に公開されている assets/face-*.webp を参照します。
- 複数キャラでGLBを共有している場合、モデル別原画も共通です。
- 実ブラウザ・本番サーバーでの全機能試験は未実施。
- マルチプレイの数値をそろえるには、参加者全員が更新版を適用してください。
