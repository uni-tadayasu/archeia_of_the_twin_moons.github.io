Riftfall Arena V28 — 運営長専用キャラクター編集ページ

ZIP生成ツール（HTML）をChromeで起動し、現在のゲーム全データZIPを選んで「更新ファイルのみ生成」を押します。

生成されるファイル:
  main.js                 キャラ編集ページを起動（キャッシュ更新）
  index.html              main.js の読み込みバージョン更新
  server/worker.js        運営長の役職トークンをサーバーで再検証して保存
  character-editor.js     専用ページ、技・能力値編集、全員への反映
  character-editor.css    PC/スマホ対応の管理画面スタイル

適用方法:
  1. 生成された差分ZIPを展開して、GitHub Pagesの同じパスへ配置。
  2. server/worker.js をCloudflare Workersにもデプロイ。
  3. ページをCtrl+Shift+Rで再読み込みし、運営長キーで認証。
  4. タイトル画面「工房と旅支度」に「キャラクター編集」が現れます。
  5. 保存された編集は次回の戦闘から反映。ゲームを開いている他のプレイヤーは最大2分程度で取得。

安全性:
  ・運営長署名トークンがなければ編集保存APIは403です。
  ・モデル・画像・役職・購入制限・ロックなどの変更は不許可です。
  ・変更データはCloudflare Durable Object Storeに保存します。既存のSTOREバインディングを利用。
  ・インストーラーはファイルをサーバーへ送信しません。
  ・他のプレイヤーにもキャラ能力値の変更が適用されます。
  ・既存のゲームZIP全体は再梱包せず、更新されたファイルだけ出力します。

注意: キャラクターのベース能力値・技名・威力・消費量などの編集に対応。技の種類（kind）・新規モデルアップロードは行いません。
