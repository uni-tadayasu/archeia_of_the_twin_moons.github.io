# 双月のアルケイア Riftfall Arena V55.26

## 適用方法

V55.25を適用済みのサイト一式を用意してください。ZIPを展開し、`index.html` が置かれているサイトのルートへ、フォルダー階層を保って上書きします。ZIPに入っている2つの説明ファイルは手元で確認できます。更新版のトップ画面を開くと、メニュー下部に **V55.26** が表示されます。

V55.26の配布物は前版からの差分12ファイルと説明書・検証結果です。サーバー側のファイル、セーブ形式、3Dモデル本体、音源は前版のものを使用します。公開サイト、GitHub、Cloudflare Workersへの反映は手動です。

## 戦闘画面

- 双月の闘技場を、朱塗りの灯籠と紅葉越しに二つの月を望む夜景に更新しました。舞台選択、対戦画面、ランクマッチのメニュー画像、舞台案内で使います。
- 石床と外周の質感、舞台ごとの照明、キャラクターの足元の影を調整しました。影は跳躍時に薄まり、無限天守でも城の床に表示されます。通常の闘技場は半径13mです。
- 画質設定とフレーム間隔に合わせて描画解像度を調整します。メニュー描画は最大30fpsです。画面サイズが大きい端末でも、描画バッファは約360万画素を上限にしています。
- ランクマッチの残り時間・再接続の表示・退出・HP・各ゲージを整理しました。画面を横にしたときは、探索マップと旅人メニューがタッチ操作を邪魔しにくい位置に並びます。ボタンの保存済み配置を使えます。

## 動作と案内

- ランク戦の検索開始の応答が途切れた場合、サーバーの検索状態を確認しながら取り消せます。試合後の再接続時は、サーバーに再挑戦の投票が届いているかに応じてボタンを復元します。
- 端末に不正な音量設定が残っている場合は既定値で起動します。範囲外の数値は0〜100%に収めます。藤原信頼の専用BGMは「旅支度」の「音量とBGM」で切り替えられます。
- 操作ガイドに主要9モードと拠点攻城戦、セーブの引き継ぎ、画質とタッチ操作の設定を掲載しました。闘技場の代替テキストと画像サイトマップを更新し、各ガイドの正規URLと構造化データを検証しました。

ブラウザ・描画・モデル・音源・通信の検証範囲は `QA_V55_26.txt` を参照してください。
