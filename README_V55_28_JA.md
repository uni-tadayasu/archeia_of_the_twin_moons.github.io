# 双月のアルケイア Riftfall Arena V55.28

## 適用方法

V55.27が適用済みのサイトで、ZIP内の更新ファイルをフォルダー階層ごと上書きしてください。上書き先は `index.html` があるフォルダーです。メニュー下部のバージョン表示は **V55.28** です。説明書と検証結果は手元で確認できます。

## 今回の修正

- **開戦** — 「構え」から「戦闘開始！」までを、戦士が操作を受け付けるタイミングと揃えました。フレームレートが低い場合や、ポーズ・タブ切替から戻った場合も、表示と操作解禁が同じフレームに進みます。
- **出撃の取り消し** — CPU戦、二対二、一人用の期間イベントでモデルを読み込んでいる間に「出撃を取り消す」を選べます。取り消した出撃は、読み込み結果が遅れて届いても開始しません。
- **ランクマッチ** — 接続が開いてもサーバーから対戦状態が届かない場合は、初回接続と再接続でそれぞれ最大27秒で準備画面に戻ります。再接続で対戦状態が届くと、待機表示を解除します。
- **ゲームパッド** — ポーズ画面から離脱を選ぶと確認画面が出ます。設定では左右で音量や選択項目を変更でき、決定ボタンで「基本操作を確認する」などの項目を開けます。
- **モデルの後片付け** — 戦士や無限天守の敵が退場した際、その個体が使用していた骨格用GPUテクスチャを解放します。

公開先への反映は手動です。検証の条件と結果は同梱の `QA_V55_28.txt` を参照してください。
