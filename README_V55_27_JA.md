# 双月のアルケイア Riftfall Arena V55.27

## 適用方法

V55.26が適用済みのサイトに、ZIP内のファイルをフォルダー階層ごと上書きしてください。上書き先は `index.html` があるフォルダーです。更新後はゲームメニュー下部に **V55.27** が表示されます。説明書と検証結果は手元で確認できます。

## トップ画面と検索向けページ

- 朱塗りの山城を双つの月が照らす新しいイラストを、開始画面とゲームメニューに採用しました。スマホ縦画面は門と月が見える専用の構図です。横画面には画面幅に合ったWebPを読み込みます。
- 開始画面から「操作ガイド」「モード紹介」「舞台案内」を開けます。メニューのゲームモード・舞台・工房への移動は、キーボードで選ぶと見出しのあるセクションにフォーカスが移ります。
- 戦闘モードガイドを追加しました。ランク戦の昇格条件、無限天守の階段とHPの引き継ぎ、拠点攻城戦の防衛設定、ストーリーの進め方を掲載しています。JavaScriptが無効のときも、各ガイドに移動できます。
- トップとガイドの正規URL、検索用の説明、WebPage・VideoGame・パンくずの構造化データ、共有画像と画像サイトマップを整備しました。実際の検索掲載は公開後に確認してください。

## 操作と戦闘演出

- 確認ダイアログ、チャット、探索の旅人パネルで、直前の移動・攻撃の入力を解除します。ランク戦の試合進行中も確認画面から攻撃が漏れないようにしました。
- ゲームパッドの入力が残っている場合、操作を再開する前にスティックとボタンを中立へ戻せます。確認画面の取消もパッドで選べます。
- スマホのスティックに中央の遊びを設け、指が離れたときやタッチが取り消されたときの復帰を安定させました。戦闘のタッチボタンには動作名を設定し、キーボードと支援技術でも入力できます。
- 一般戦士の材質に布・金属の違いが出る光沢と、輪郭を読みやすくする光を加えました。既存のテクスチャとモーションを使用します。
- 斬撃、属性術の陣、衝撃波、火花と光の残り方を描き直しました。画質設定に応じて同時表示数を調整し、「演出の動きを抑える」設定や端末の動きを減らす設定では動きや光を抑えます。

ゲームの公開先への反映は手動です。適用前の検証範囲は `QA_V55_27.txt` に記載しています。
