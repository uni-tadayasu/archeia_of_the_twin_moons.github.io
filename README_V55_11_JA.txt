Riftfall Arena V55.11 — 城内・洞窟CGステージ / 無限天守背景 / 一般キャラ差別化

【反映する内容】
・無限天守：ゲームルールを変えず、和風/洋風CG城内背景を選べるようにしました。
・攻城戦：相手の城拠点が和風なら全階層和風、洋風なら全階層洋風の城内CG画像を表示します。
・ワールド：地域名が洞窟・神殿・古城などのダンジョンに入った時、背景を洞窟/遺跡CGに切り替えます。
・一般キャラ：既存の13基本GLBから生成されたキャラクターに、衣装/頭飾り/体形の固有バリエーションを適用。
・キャラ選択：実際の固有外見を描画し、個人ID別の画像キャッシュを使います。

【重要】
・ゲームの戦闘判定、HP持越、ランキング、スキル、セーブ、オンライン、役職権限は変更しません。
・100個の完全独立した新規GLBファイルを新たに同梱したものではありません。
・今ある3Dワールドは引き続きWebGLで描き、CG画像は空間背景として使います（3D内の全オブジェクトの置換ではありません）。

【導入手順】
1. GitHubの現在のリポジトリをバックアップ。
2. ZIP内の「assets」フォルダーを現在のGitHubの同じ相対パスにアップロード。
3. 同梱の index.html は現行版を基準に更新したものです。最新版と差分がある場合は PATCH_SNIPPET_index.html.txt の行だけを今の index.html に追加。
4. GitHub Pages反映後、PCならCtrl+Shift+R、スマホならサイトデータを再読込。
5. 無限天守モード選択付近に追加される和風/洋風ボタンで背景を選ぶ。
