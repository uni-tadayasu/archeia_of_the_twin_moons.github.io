# 双月のアルケイア Riftfall Arena V55.31

## 無限天守の移動修正

無限天守の移動を画面基準に揃えました。上入力は画面の奥、下入力は手前、左右は画面の左右へ進みます。WASD・方向キー、スマホの左スティック、ゲームパッドに適用します。

自動視点は、向きが移動に引きずられないよう、基準方向を保ってプレイヤーを追います。手動で向きを回した場合は、画面に見えている向きに合わせて移動します。壁ぎわで視点が上からに近づくときも、画面の左右を維持します。

## 適用手順

1. V55.30適用済みのサイトを用意します。
2. このZIPを展開して、`index.html` があるフォルダーへ、同じ階層で更新ファイルを上書きします。
3. ページを再読み込みし、メニューのフッターが **V55.31** であることを確認します。

更新対象はクライアントの4ファイルです。Workerの再デプロイは不要です。
