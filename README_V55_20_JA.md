# Riftfall Arena V55.20 差し替えガイド

指定の「archeia_of_the_twin_moons.github.io-main (1)(3).zip」を基準にした更新です。今回添付の「(1)(4).zip」とは、収録ファイル1,110件のパス・サイズ・CRCが一致しました。

## 適用

1. 既存のゲームフォルダーをバックアップします。
2. ZIPを展開し、既存の index.html があるフォルダーに、階層を保ってファイルを上書きします。assets/ と server/ は既存フォルダーに統合します。
3. 新しい攻城戦を使用するには、既存のCloudflare Workerへ server/worker.js を先に反映します。既存の環境変数、Durable Objectバインド、wrangler.toml を使用します。
4. 公開後は、メニュー下部に V55.20 が表示されることを確認します。Workerの /health もバージョン 55.20 を返します。

## 無限天守と視点操作

- 約94m四方の木造城内に本丸、大広間、長回廊、階段室を配置しました。床板、格天井、梁、障子、行灯を備え、カメラが壁に入り込むと距離を調整します。
- 出現待ちの敵を含めて全員を倒すと階段が開きます。階段に進むと、同じ戦士と残りHPで次の階へ移動します。
- 無限天守とストーリーは自動視点で開始します。PCは Q／E またはマウス中ボタンのドラッグで回転し、Rで自動視点に戻ります。スマホは画面の左右ボタンまたはドラッグ欄を使い、「自動」で戻します。
- 通常戦と攻城戦は半径13mです。ストーリー以外の結果画面と一時停止画面では、直前の選択・準備画面へ戻れます。アドベンチャー戦からは休憩所に戻ります。

## 拠点攻城戦

- 自分の拠点で「階層別の防衛ボス」を開き、第1〜10階の任意の階を選んで保存します。未開放の階も設定できます。既定の最上階は領主が守ります。
- Workerが同期済みの所有者とキャラクターの使用権を確認し、所有者ごとに保存します。攻撃側には出撃時点の防衛編成が反映されます。
- 新規攻城戦はアクション戦です。移動、通常攻撃、技、奥義、防御を使います。各階1回の回復はPCで H、スマホで「癒」です。勝利後は次の階の準備へ進みます。
- 旧版で始めたコマンド式の攻城戦は、拠点画面から続けられます。

## 外観とデータ

一般戦士は既存のモデル、骨格、モーション、テクスチャを使い、明暗と輪郭光をCGイラスト風に整えました。メニューは和紙色の扉絵を採用し、画面ごとに墨緑、朱、藍、青磁などを使い分けています。

戦士のお気に入りを同期側に統一しました。同期側に登録がなければ従来の端末側のお気に入りを引き継ぎます。共通BGMは場面切替でも再生位置を維持します。音声自動再生が制限される端末では、最初のタップやキー操作で再生が始まります。

タイトルと説明文、共有画像、構造化データ、robots.txt、sitemap.xmlを更新しました。正規URLには既存の https://www.kasai-solutions-inc.com/ を使用しています。
