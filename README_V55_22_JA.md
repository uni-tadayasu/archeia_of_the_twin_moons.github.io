# Riftfall Arena V55.22 最終版の適用

基準は添付の「archeia_of_the_twin_moons.github.io-main (1)(3).zip」です。V55.20・V55.21の修正も含む差分です。最新版の全データ、またはV55.21を適用済みのフォルダーに、このZIPを1回重ねて使います。

1. `index.html` のある階層にZIPの中身を上書きします。既存の `assets/` と `server/` の階層を保ちます。
2. ランク戦を公開する際は、先に既存のCloudflare Workerを更新します。使用中のWrangler設定に、同梱の `server/wrangler.toml` にある `RANK_HUB`、`RANK_DUEL` と `v5-ranked` の追加マイグレーションを取り込みます。これまでのマイグレーション、バインディング、秘密変数、公開ドメインを引き継ぎます。実環境の `ALLOWED_ORIGINS` や `STRIPE_LINKS` を個別に変更済みの場合は、その値を引き継ぎます。
3. Workerは `server/worker.js`、`server/ranked.js`、`server/ranked-rules.js` を含め、既存のデプロイ手順で反映します。同梱の構成を使う場合は、`server/` で `npm install`、続いて `npx wrangler deploy` を実行します。メインサイトはその後、通常の手順で反映します。独自のAPIホストを使う環境では、`config.js` のAPIホストと、`index.html` の `connect-src` にあるWSSホストを合わせます。
4. 反映後は、メニューの「ランクマッチ」から出撃します。対戦に入るには「旅支度・設定」のセーブ同期が必要です。同期後の戦績は同じプレイヤーIDに紐付き、別の端末でも同じ同期セーブで表示できます。

Cloudflareの新規Durable ObjectはSQLiteのマイグレーションとして設定しています。 [Cloudflareの設定資料](https://developers.cloudflare.com/durable-objects/best-practices/access-durable-objects-storage/)

## ランク戦のルール

- 世界共通で1対1のマッチングです。近いポイントの人を優先し、待機が長いほど検索範囲を広げます。
- 全員HP1,000のランク戦用バランスです。一般戦士のモデル、色、アニメーションを使い、走りや間合いには小さな個性があります。技Aは踏み込み、技Bは飛び道具、Hは回復、奥義は大きな範囲攻撃です。通常攻撃は3段の連撃です。
- 試合は最大2分30秒です。KOまたは時間切れ時の残HPで勝敗が決まり、同じHPは引き分けです。試合前の取り消しはポイントに影響しません。試合中のリタイアは敗北として確定します。
- 対人戦は相手とのポイント差に応じて、勝者に15～36 ptを加え、敗者から5～16 ptを引きます。保有ポイントの下限は0 ptです。引き分けと双方切断による無効試合ではポイントは増減しません。
- 再挑戦は24秒以内に両者が選ぶと成立します。片方が退出、または期限切れになるとマッチを終了します。接続が切れた場合の猶予は合計22秒です。
- ボット抽選は人の候補がいないまま60秒を過ぎたときから30秒間隔で行い、各回12％です。ボットの反応や技選びはポイントと戦績に応じて変化します。ボット勝利はUTCの日付ごとに3勝分まで各8 ptを加算します。ボットは再挑戦に同意します。
- 世界順位の上位50人、自分の順位・最高ポイント・連勝、直近10件を確認できます。
- 添付の「Hear your voice.mp3」はランク戦の検索、試合、決着を通してループ再生します。既存のBGM音量を使います。
