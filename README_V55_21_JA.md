# Riftfall Arena V55.21 更新手順

基準は添付の「archeia_of_the_twin_moons.github.io-main (1)(3).zip」です。V55.20の無限天守・攻城戦の更新も含みます。元の全データへ、このZIPを1回重ねれば適用できます。

1. 添付の全データを展開します。すでに V55.20 を適用したフォルダーにも重ねられます。
2. このZIPを開き、`index.html` がある階層に中身を上書きします。`assets/` と `server/` の階層を保ちます。
3. 手元で確認するときは、プロジェクトのルートで `python -m http.server 8080` を実行し、`http://localhost:8080/` をブラウザで開きます。オンライン機能を使う場合は従来と同じ公開元とAPI設定を使います。
4. 公開する際に Cloudflare Workers が V55.20 より前の場合は、同梱の `server/worker.js` を既存の環境変数・ストレージのまま手動で反映します。V55.20 の攻城戦 API を反映済みなら今回の Worker 再反映は不要です。

## 主な改良

- 双つの月と木造天守の新しい扉絵に合わせて、藍、朱、青磁、真鍮の配色で再構成しました。タイトル、出撃先、戦士・舞台選択、設定、ロード表示、戦闘中の操作を整えました。
- 元のGLBの輪郭・衣装を引き継ぎ、一般戦士のマテリアルを調整しました。GLBに収録された歩行・走行・斬撃・構え・詠唱・奥義などを適切な場面で選択し、走行切替や着地後の姿勢を自然につなぎます。収録モーションのないモデルは既存の専用モーション、または表示用の姿勢補正を使います。
- 斬撃、火花、詠唱、衝撃環はブラシ状の透過画像を使います。端末と映像品質に応じて同時表示数を調整します。舞台と戦士の画像を遅延読み込みし、スマホでは既存の戦士絵を活かして3Dポートレート用の追加読み込みを抑えます。
- スマホは左スティックと技ボタンの同時操作に対応します。ポインターが解除されたとき、一時停止したとき、別画面へ移ったときに入力状態を解放します。オフライン戦では、動作の終わり際に押した次の入力を短時間だけ受け付けます。
- 無限天守とストーリーの視点は、PCの Q/E、画面の回転ボタン・視点欄のドラッグ、または標準マッピングのゲームパッドの右スティックで回せます。R、画面の「自動」、右スティック押し込みで自動視点に戻ります。
- 無限天守は全敵撃破で階段が開き、残HPを次階へ持ち越します。拠点所有者は10階分の防衛ボスを設定できます。通常コロシアムと攻城戦の戦闘半径は13mです。
- SEO用に、起動前に読める `play-guide.html` を追加しました。サイトマップ、各ページの説明文と正規URL、ゲームの構造化データ、共有画像を更新しています。正規URLは V55.20 の `https://www.kasai-solutions-inc.com/` を使用します。

既存セーブは上書き更新後も同じブラウザ・同じ公開URLで引き継ぎます。初回のBGM再生はブラウザの仕様によりクリック・タップ・キー入力で開始します。テスト内容は `QA_V55_21.txt` を参照してください。
