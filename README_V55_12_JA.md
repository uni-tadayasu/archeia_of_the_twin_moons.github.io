# Riftfall Arena V55.12 — 多彩なCG城内・洞窟・遺跡 / 描画品質改善

## 重要
無限天守の階層進行・HP持ち越し・ランキング、オンライン通信、運営権限、課金・セーブ、キャラクター能力・攻撃判定は変更しません。
今回の変更はステージの視覚演出、キャラ画像の再読み込み、外見データ点検機能です。

## 新機能
・無限天守：和風／洋風のテーマ選択を維持し、各テーマの背景が階層ごとに3景へ切り替わります。自動か任意の第一〜第三景を選択できます。
・攻城戦：和風拠点なら全階層が和風、洋風拠点なら全階層が洋風です。階層ごとに同じテーマ内の3背景を切り替えます。
・ワールドダンジョン：洞窟／遺跡を各3景の光・色調で演出します。場所ごとの背景を安定して表示します。
・設定：背景演出を自動／有効／省電力から選択。動きを減らす端末設定に対応。
・モデル画像：選択画面でGLB画像の生成に失敗した際、設定画面から再読み込み可能。
・設定画面：一般キャラの人数／素体数／固有外見データ数の点検。

## 一般キャラについて
100人分の固有外見データを利用します。ただし個別GLB100ファイルではありません。
基本GLBを共有し、86人の固有形状・衣装・頭飾り等を生成する仕組みです。
実際に全GLBの表示を検証するにはPC・スマホの実機テストが別途必要です。

## 導入方法
1. GitHubの最新版をバックアップ。
2. このZIPに含まれる `index.html`、`assets/` の変更ファイルを同じ相対パスに上書き／追加。
3. 以前のV55.11をインストールしていなくても、必要なV55.11視覚・外見ファイルを同梱しています。
4. GitHub Pages公開後はブラウザキャッシュを強制更新（Windows Chrome: Ctrl+Shift+R）。
5. 無限天守和風／洋風、階層進行、攻城戦の防衛拠点スタイル、ワールド、キャラ選択、スマホ操作を確認。

## 制限と注意
・これは既存の戦闘フィールドの背景とCG画作りを強化する実装です。新しい3D当たり判定付き建築物・独立GLB100体を作るものではありません。
・攻城戦で再開した直後に、相手拠点の種類が保存できていない場合は前回の見た目が残ることがあります。戦闘の勝敗や報酬には影響しません。
・公開後の実機／オンラインでの総合動作確認は未実施です。
・Cloudflare Workersの更新は不要です。GitHub書き込み権限がない場合はZIPをGitHubへ手動アップロードしてください。
