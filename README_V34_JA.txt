Riftfall Arena / V34 UIレイアウト・重なり修正
============================================

【使い方】
1. 「Riftfall_UI_V34_Installer.html」をWindowsのChromeで開きます。
2. 現在のゲーム全データZIP（例: archeia_of_the_twin_moons.github.io-main (9).zip）を選びます。
3. 「更新ファイルのみZIPを生成」をクリックします。
4. 生成された差分ZIPを解凍し、フォルダー構成を維持してGitHubへアップロードします。
5. GitHub Pagesデプロイ後に、ブラウザをCtrl+Shift+Rで更新してください。

【更新されるファイル】
 index.html                           レイアウト補正CSS/JSの読み込みを追加
 assets/rf-ui-safe-v34.css           PC/スマホ・画面の重なり/はみ出し対策
 assets/rf-ui-safe-v34.js            画面サイズ・タッチ領域を見て技パネルを配置

【重点修正】
・タイトル/モード選択/編成/鍛錬画面の幅溢れ防止、長い文字の折り返し
・戦闘HPの左右枠・中央の休む/灯力ゲージ・技名の重なり軽減
・スマホの操作ボタンと技選択パネルの衝突回避、技パネル複数表示時の左右分離
・チャット表示中は技選択パネルを隠し、メッセージ欄・入力欄を表示
・運営長用キャラクター編集画面の操作ボタン/入力欄/一括比較表をレスポンシブ化
・一括比較表は幅620px以下ではカード型の縦並び表示
・アドベンチャー休憩所の操作パネル、ワールド/フレンド画面の表示位置調整
・小さな横画面、セーフエリア、縦持ちスマホへの対応
・キーボードのフォーカス移動、スクロール、軽量な画面更新を維持

【その他】
・戦闘ロジック、強化値、モデル、音楽、ネットワーク認証、Cloudflare Workerは変更しません。
・差分ZIPは毎回ユーザーの最新ゲームZIPを読み取って作成するため、ゲーム全体の古いファイルには戻しません。
・バックアップを取ってから適用してください。
・ブラウザの開発者ツールで RiftfallUILayoutAudit() を実行すると、表示中の主要UIが画面幅を越えていないか確認できます。
