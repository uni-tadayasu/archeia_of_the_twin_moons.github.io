Riftfall Arena — 魔卵獣ゼルグリム V7.3 / 孵化フリーズ対策

更新対象：maou-abilities.js （GitHub リポジトリのルートに上書き）

前提：V7.2の assets/models/maou-egg-zelgrim.glb をアップロード済み。
まだの場合は同梱の assets/models/maou-egg-zelgrim.glb も配置してください。

【修正】
・魔王が戦闘へ入る際、軽量GLBを読み込み終えた後、ゼルグリムの戦闘用3DモデルとFighterを1体だけ作成して非表示で待機。
・卵孵化時のモデル生成・GLB複製を禁止。孵化したら待機済みモデルを表示するだけ。
・準備できていなければ卵が最大約3.6秒待ち、その後、安全に召喚を中止（フレームを止めない）。
・召喚獣は最大1体、3回被弾で消滅、HPバーなし、自動追尾攻撃。
・消滅時は待機状態に戻すため、2回目以降も再生成不要。
・戦闘終了時だけ待機モデルも確実に解放。
・その他の魔王の能力、通常モデル、音声、ゲームモードは変更しません。

大切：スマホで絶対にフリーズしない保証はできません。
この修正は孵化瞬間の重いモデル生成を排除しますが、メモリ不足や別の例外は残り得ます。
動作確認は JavaScript の構文・制御処理の検査までです。
Chromeで古いキャッシュを読んでいる場合は、キャッシュを更新してください。
