Riftfall Arena / 魔卵獣ゼルグリム V7.2（フリーズ対策）

上書きするファイルは2つだけです：
  /maou-abilities.js
  /assets/models/maou-egg-zelgrim.glb

魔王本体・その他のモデル・ゲームのステータス・冒険モードなどは変更しません。
卵は一度に1個、召喚獣「魔卵獣ゼルグリム」は最大1体、3回被弾すると消滅、HPバーなし、自動追尾です。

重要:
- この専用の非常に小さいGLBは約73KBです。元の20MBの魔王モデルを複製しません。
- モデルの元の色を維持し、緑色への再着色は行いません。
- 以前の青緑の八面体を組み合わせた仮モデルではなく、頭・顔・角・腕・脚・外套・尻尾のある独立した召喚獣です。
- 複数召喚防止、読み込み失敗時の中止、戦闘終了後の生成禁止を実装しています。
- 「絶対にフリーズしない」は保証できません。スマホ性能やブラウザのメモリ状況にも左右されます。
- 元の魔王本体と同じ姿を再現したモデルではありません。別途提供された専用軽量GLBがある場合はそのファイルへ差し替える必要があります。

GitHubのルートと assets/models/ に配置し、Ctrl + Shift + R で再読み込みしてください。
現行の「V7」システムを前提とします。
