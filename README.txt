Riftfall Arena / 双月のアルケイア 追補パッチ

適用: ファイルを同じ相対パスで既存最新版に上書きしてください。
更新: data.js, game.js, main.js, field.js, index.html, voice.js, server/worker.js
音源・GLB・メール・セーブデータは変更していません。

1. 鍛錬の工房に「詠唱の研鑽」1項目追加。Lv1あたり3%、最大45%短縮。
2. 限界突破にも対応。ただし通常技の下限0.24秒、奥義0.90秒、秘奥義1.40秒。
3. ヴァルガルドの氷技2つと氷の最上級奥義を拡張。元モデルは無変更。
4. 存在しないstory-theme.mp3とboss-theme.mp3参照を現行配布曲に変更。
5. タイトル／メニューではタイトル曲を優先。ヴァルガルド登場時は戦闘・フィールド曲より優先。
6. 設定にBGM・戦闘効果音・戦闘ボイス・操作音の独立音量スライダーを追加。
7. Web Audioによる効果音生成・音声設定を更新。

重要: server/worker.jsを更新する場合、既存Secrets/Durable Objectsバインディングを維持し、先にテスト環境で検証。
オンライン同期強化値の検証結果を一致させるにはWorker更新が必要です。
ブラウザの仕様上、初回の音再生にはユーザー操作が必要です。
