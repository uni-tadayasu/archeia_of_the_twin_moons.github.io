RIFTALL GAME – GAIZORG / VALDARION UPDATED ONLY PATCH

1. riftfall_update_builder.html を Chrome で開く
2. 現在のゲーム ZIP を選択（必須）
3. 必要に応じて最新GLBを個別に選択（元の軽量モデルに変更を加えない）
4. 「更新ファイルのみのZIPを生成」を押して、リンクからダウンロード
5. コードZIPの変更ファイルだけGitHubリポジトリに上書き
6. 各モデルZIPから assets/models/ のGLBを配置
7. server/worker.js を Cloudflare Workers にもデプロイ

キャラセレクト画像はブラウザ実行時、ゲーム内のGLB実モデルからWebPを生成します。
モデルの色・形を推測したイラストをメイン画像に使用しません。

既存のヴァルガルド最終改良技はそのまま、HP0第二形態も一度だけ復活。
ガイゾルグは炎属性、常時スーパーアーマー、炎魔法陣30s、火傷と攻撃力半減10s、爪、炎弾、長押し火炎放射、奥義・秘奥義。
ヴァルダリオンは無属性最強、常時スーパーアーマー、無魔法陣30s、被弾解除拘束、分身4体の自動追尾（HPバーなし・一撃で消滅）、最上位魔法。

現在のゲームに適用する差分であり、すでに公開済みのゲームには自動反映されません。
オンライン・実際のGLB描画は公開環境でのテストも必要です。
