Riftfall Arena / 魔王『卵1個・緑分身1体』軽量化差分 V6.1

対象: V6を反映済みの『双月のアルケイア』
変更したファイル: maou-abilities.js （1ファイルのみ）

更新手順:
1. このZIPを展開。
2. maou-abilities.js をGitHubリポジトリのルートに上書き。
3. GitHub Pagesの公開更新後、Chromeで Ctrl+Shift+R による強制再読み込み。

変更点:
- 口から出す卵は同時に1個のみ、孵化する緑分身も最大1体。
- 卵の飛行中に連発しても追加の卵を生成しない。
- 分身は相手を自動追尾。3回攻撃を受けると消滅（HPゲージなし）。
- 分身消滅時、不要な3Dオブジェクトを解放して蓄積を防止。
- キャラクター選択の技説明も卵1個・分身1体に更新。
- 他の魔王の究極光魔法・虹色防御・30秒自動回復・50％復活・完全回復・赤い眼光レーザーは変更なし。
