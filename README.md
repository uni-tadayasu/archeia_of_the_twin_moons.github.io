# 双月のアルケイア — Rebirth

双月の和風ファンタジー世界を舞台にしたブラウザ3DアクションRPG。新しいホーム・出撃画面と独立した戦闘エンジンを `index.html` / `rebirth/` に実装しています。Three.js 0.184.0 とデコーダはローカル同梱し、起動時の外部CDN依存をなくしました。

## 新章で遊べる内容

- 14人の一般戦士、4つの舞台。11人はモデル内蔵の骨格モーション、ハーラン・ヴェルカ・ノアは元の見た目を保つ13ボーンの自動骨格と歩行・攻撃・防御・詠唱モーションを使用。
- 会話と戦闘を繋ぐ4章の物語。
- 10面の冒険、5面後の休息所、最終ボス。
- 残り体力を引き継いで挑む無限天守。
- CPU強度1〜100%の自由対戦。
- 3段連撃、固定スロットの技、防御、回避、回復、奥義。敵の攻撃予告と障害物。
- 灯晶報酬、体力・攻撃強化、記録、お気に入り、検索。
- キーボード、マウス、タッチ、標準ゲームパッド。3段階の画質、音量、動きを抑える設定。
- 端末内の自動保存、JSONバックアップの書き出し・読み込み。

## 既存版との関係

`classic.html` に更新前の入口を保存しています。ホームの「オンライン・運営」から、既存のオンライン対戦・イベント共闘・拠点攻城戦・ショップ・運営機能を利用できます。既存の `main.js`、サーバー、運営権限、所有キャラクターとセーブキーは変更していません。

新章の進行・灯晶・強化は `arkeia.rebirth.v1` に分離され、既存オンラインの資産とは共有されません。新エンジンへのオンライン移植、全限定キャラクター固有技の再実装はこの版の対象外です。新しい3D戦闘は実装済みですが、それら従来機能は従来エンジンで動作します。

## 操作

| 操作 | PC |
|---|---|
| 移動 | WASD / 矢印 |
| 通常攻撃 | J / 画面の左クリック |
| 技A | K / 右クリック |
| 技B | I / U |
| 奥義 | L |
| 回復 | H |
| 防御 | Shiftを押している間 |
| 回避 | Space |
| 一時停止 | Esc |

技A/Bは立ち止まった状態と移動中で使う技が切り替わります。スマートフォンでは左スティックと右側の操作ボタンを使います。音声はブラウザの仕様により最初の操作後に開始します。タブを離れると戦闘は一時停止します。

## 開発と確認

ゲーム本体の起動と単体テストは Node.js 22 以上のみで動きます。ブラウザの統合テストには npm ci と Playwright の Chromium が必要です。

```sh
npm run dev
npm run check
npm test
# CI と同じブラウザ統合テスト
npm ci --ignore-scripts
npx playwright install --with-deps chromium
npm run test:browser
```

`npm run check` は構文・DOM・ローカル依存・画像・モデルとその外部バッファを検査します。`npm test` は戦闘、当たり判定、ガード、回避、技、難易度、セーブと報酬などの動作を検証します。

## mainへの自動取り込み

同一リポジトリの `codex/riftfall-*` ブランチから `main` へのPRを作成すると、検証成功後に `.github/workflows/rebirth.yml` が自動でマージします。下書き・fork・検証後に変更されたSHAは対象外です。詳細は [自動取り込み](docs/AUTOMATION.md)。

## 構成

- `rebirth/app.mjs` — 画面・会話・モード進行・HUD
- `rebirth/combat.mjs` — 描画から独立した120Hzの戦闘シミュレーション
- `rebirth/renderer.mjs` — モデル、アニメーション、舞台、カメラ、エフェクト
- `rebirth/catalog.mjs` — 原作の戦士データと新章の構成
- `rebirth/save.mjs` — 検証付きセーブ、報酬、強化
- `rebirth/input.mjs` / `audio.mjs` — 入力・音声のライフサイクル
