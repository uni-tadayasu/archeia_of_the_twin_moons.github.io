双月のアルケイア / Riftfall Arena 4体統合アップデート 2026-11-08
================================================================
※ BATファイルは不要です。

この一式は、前回の未ダウンロード分を含むブラウザ更新ZIP生成ツールです。
4つの大容量GLB原本は、このZIPには収録されていません。
理由：この実行環境ではチャット添付GLBの実バイナリが制作コンテナから読めず、
ファイルを「収録済み」と偽ってZIPを作ることができないためです。
生成ツールをChromeで開き、元のゲームZIPと4つのGLBを選んでください。
選んだモデルは完全な元バイト列のまま更新ZIPへ取り込まれます。
この手順にアップロードや別のサーバーは必要ありません。

【更新する4体】
A. ヴァルガルド（運営長）
   入力モデル: mecha action figure 3d model(1).glb
   公開先: assets/models/iron-warlord.glb
B. 機神ギガンテス（運営のみ。運営長は選択不可）
   入力モデル: mecha 3d model.glb
   公開先: assets/models/operator-gigantes.glb
C. ガイゾルグ（運営長）
   入力モデル: bowser 3d model(2).glb
   公開先: assets/models/gaizorg-boss.glb
D. 虚無機神ヴァルダリオン（運営長）
   入力モデル: character 3d model.glb
   公開先: assets/models/valdarion.glb
   属性：無。無属性のため技で属性状態異常を付加しない。
   特殊ガード：「絶対護装《無傷の煌鎧》」
   30秒間、被ダメージ50%・ひるみ/ノックバック無効・攻撃続行。
   ダメージは受ける（無敵ではない）。効果終了から45秒後再使用可能。
   破壊系の最高位魔法／禁呪／奥義を設定済み。

【アドベンチャーモード】
- 以前の gaizorg-adventure.js を維持して機能を拡張。
- タイトルから「アドベンチャー」を選択。
- キャンプ、ポータル、全10戦、章進行記録、最終ガイゾルグ戦。
- ガイゾルグは元GLBと新しい骨格・歩行・走行処理を共有。
- ヴァルガルド/機神ギガンテス/ガイゾルグ/ヴァルダリオンも、
  適切なアカウント権限があれば冒険に使用可能。
- 運営長キャラ選択の可否は、既存の役職認証を利用。

【作成手順（Windows Chrome）】
1. 「Riftfall_4体統合_更新ZIP生成.html」をダブルクリック。
2. 元の「archeia_of_the_twin_moons.github.io-main(3).zip」を選ぶ。
3. 上記の4つのGLBファイルを順に選ぶ。
4. 「更新されたファイルのみZIP」を選択して生成。
   サイト全体が必要なら「全データ結合ZIP」を選択。
5. 生成ZIPを解凍し、GitHub Pagesリポジトリのルートに配置。
   index.htmlはリポジトリのルートです。ZIPはGitHub上で自動展開されません。
6. server/worker.js の変更をCloudflare Workersへも別途デプロイ。
   GitHubだけに置いても稼働中のWorkerは更新されません。

【ゲーム動作確認の範囲】
- HTML/JSの構文チェック、テスト用元ZIPに対する差込・ZIP出力検査まで実施。
- GLB内部の骨・ウェイト・原点・軸向きがこの実行環境から直接検証できないため、
  実際のゲーム画面での忠実な歩行/走行/攻撃アニメと、ネット対戦動作は未検証です。
- 元GLBの頂点/UV/テクスチャは変更せず、骨がなければゲーム実行時に19関節の
  推定骨格を作成して動かします。専用にウェイトペイントしたアニメとは異なり、
  複雑な一体型装甲・非人型モデルでは不自然な変形が起きる可能性があります。
- キャラセレクトでは使用権があればGLBを読み込み、3Dモデルから全身像を
  WebGLでプレビュー生成。見本画像（ヴァルダリオン）はコンセプトイラストです。
  GLB表示に成功した場合は、実際のモデルの3Dビューが優先されます。
- Cloudflare権限については、既存の署名付きプロフィールAPIを使用します。
  ブラウザ側のガード処理とサーバー側のすべての戦闘値を一致させるための
  実機オンラインテストは引き続き必要です。

【容量】
- 4つのモデル合計でおおむね240MB前後。10MB以内には収まりません。
- 個々のモデルがGitHub Webアップロードの上限を超える場合は
  GitHub Desktop またはgit pushを使ってください。
- GitHub Pagesの公開URLでGLBがHTTP 200か検証してください。
- バイナリGLBは既存の他のキャラクターや音楽に影響しません。

※ 元ZIP側に gaizorg-adventure.js / server/worker.js が存在しない場合、
   ツールは明示的なエラーを出します。別バージョンのベースと誤って統合しないためです。
