# Riftfall Arena V55.24 更新手順

V55.23を適用したフォルダーに重ねる差分です。ZIPの階層を保ち、`index.html` のある場所に展開してください。ランク戦の参加枠を更新するため、Cloudflare Workerには同梱の `server/worker.js` を反映します。V55.23と同じ単体ファイル構成です。稼働中のバインディング・秘密変数・ドメインを引き継ぎます。追加のデータ移行はありません。Workerの後にサイト側を更新し、ページを開き直してください。

## ランクマッチの戦士選択

セーブを同期すると、一般枠100体を選べます。運営長・運営の認証を済ませると、その役割の専用枠が加わります。Workerが認証済みの役割を確認して、選択一覧を返し、参加時にも同じ条件で判定します。

| 認証 | 選べる戦士 |
| --- | --- |
| 一般 | 一般枠100体 |
| 運営長 | 一般枠100体と運営長専用10体 |
| 運営 | 一般枠100体と運営専用5体 |

- **運営長専用**　天子、ヴァルガルド、ガイゾルグ、虚無機神ヴァルダリオン、魔王、蒼海神皇ネプテリオン、右大臣、城崎三位、藤原信頼、宇邇宮忠靖親王
- **運営専用**　セラフェル、ルミナリア、ヴェスペラ、ザルグレイヴ、機神ギガンテス

追加された戦士もHP1,000と共通技のランク戦ルールで戦います。速度と攻撃の間合いにはランク戦の範囲を適用します。キャラの見た目、動き、技の演出は各戦士のデータを使います。

## 藤原信頼の専用BGM

「旅支度・設定」の「藤原信頼の専用BGM」で切り替えます。初期値はオンです。チェックを外すと、その場面のBGMへ切り替わります。設定は現在のブラウザに保存され、開き直したあとも有効です。ランクマッチでは全戦士がランク戦の曲を使用します。

検証結果は `QA_V55_24.txt` を参照してください。
