Riftfall Arena V32 — キャラクター全員をテンプレート一括編集

変更ファイル（2個のみ）
- character-editor.js
- character-editor.css

導入：GitHubの同名ファイルへ上書きしてデプロイしてください。
V31のサーバー保存APIをそのまま利用するため Cloudflare Worker の更新は不要です。

運営長のキャラクター編集ページを開き、「全キャラクター一括バランス編集」を使います。
- テンプレート：役割別自動／一般／雑魚敵／小ボス／中ボス／大ボス／ラスボス
- 対象：全員・一般のみ・運営系のみ
- 編集範囲：能力値のみ（推奨）／能力値＋技性能／全ランダム
- スロット数：維持または1～24、固定/順番：維持・固定・順番
- 名前/属性を維持、表示身長を維持、ガイゾルグHPトップ維持を選択可能
- 「一括変更をプレビュー」→ 比較表 → 「確認して一括保存・公開」

保存前のランダム生成はサーバーデータを書き換えません。運営長のトークン確認を実施します。
既存モデル・BGM・画像・ロール権限は変更しません。
個別編集機能、V31の技24スロット、テンプレート一括ランダム生成は維持します。

特別な攻撃技は専用JavaScriptにダメージが記述されているため、能力値/技データの変更が一部反映されない場合があります。
また、全員を同一階級テンプレートに変更すると戦力帯が近くなります。役割別自動を推奨します。
