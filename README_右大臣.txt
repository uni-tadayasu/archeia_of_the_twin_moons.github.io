キャラ：右大臣（運営長専用、呪属性）
Shift/I=呪いの結界(30秒、クールダウンなし)
J/Z=呪印(ロックオン、最大HP10％×5回、同一対象へ重複なし)
K/X=おにび(2追尾弾、10秒間のやけど、合計最大HP1/15)
U/V=呪いの光(両目から紫の光線スイープ)
H=おにび、L/C=呪いの光（別の新技は発生しません）

効果の一部は通信仕様上、オンライン相手では攻撃上限/状態異常の検証を受けます。
ブラウザでCtrl+Shift+Rを押して最新コードを読み込んでください。
