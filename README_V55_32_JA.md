# 双月のアルケイア Riftfall Arena V55.32

- **無限天守のカメラ** — 壁や角で後方スペースが狭くなると、天井の内側でカメラの高さと視野角を調整します。敵への接近や広間への出入りでも共通の縮尺を使います。壁を避けるときは、視点の高さや傾きが変わることがあります。
- **メニューの背景** — 出撃先、工房、設定、ポーズ、各モードの選択ボタンなどに薄い背景画像を入れました。画像の縦横比を保ちながら、ボタンの形に合わせて全面を覆います。
- **撃破報酬** — 既存のモードで敵を倒すと、原則として1体につき **灯晶5** を獲得します。従来の勝利・クリア報酬とは別に加算します。ランク戦と拠点攻城戦では、サーバーで確定した撃破が対象です。

## 適用手順

1. V55.31適用済みのサイトを用意します。
2. ZIPを展開し、サイトの `index.html` があるフォルダーへ更新ファイルを階層ごと上書きします。
3. ランク戦と拠点攻城戦の撃破報酬を有効にするには、更新した `server/worker.js` で既存のCloudflare Workerを再デプロイします。
4. ページを再読み込みし、メニューのフッターが **V55.32** であることを確認します。

ローカルでの検証結果は同梱の `QA_V55_32.txt` に記載しています。
