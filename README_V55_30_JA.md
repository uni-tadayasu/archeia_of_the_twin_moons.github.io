# 双月のアルケイア Riftfall Arena V55.30

## 適用方法

1. V55.29適用済みのサイトを用意します。
2. ZIPを展開し、`index.html` があるフォルダーへ、同じフォルダー階層で更新ファイルを上書きします。追加された `assets/rf5530/` もまとめてコピーします。
3. プレビューでメニューを開き、フッターの **V55.30** と「ストーリーモードⅡ」の表示を確認します。公開は確認後に普段の手順で行ってください。

この更新はフロントエンドだけで適用できます。基準のV55.29までに必要だったWorkerの更新は、その版のREADMEに従ってください。構文・動作・計測の条件は同梱の `QA_V55_30.txt` に記載しています。

## 更新内容

- **ストーリーモードⅡ** — 一人の戦士を選び、横から見た一対一の戦場で全4章の「月渡り」を進めます。左右移動、ジャンプ、防御、通常攻撃、技、奥義を使えます。進行は従来の物語とは別に記録します。
- **物語の探索フィールド** — 街道、地表、遠景、光と霧を調整し、画面内の目印で進む方向を読み取りやすくしました。
- **無限天守** — 松明の木造回廊、梁のある広間、金屏風、進行方向に向けた階段室を追加しました。最後の敵を倒すと階段が開き、残りHPを次階層に持ち越します。手動と自動のカメラを使えます。
- **起動・通信** — 3Dモデルや戦闘用素材を必要時に読み込みます。起動画面のCSSを2本にまとめ、同じモジュールの重複取得を減らしました。ランク戦では認証を共有し、対戦状況とランキングを並行取得します。
- **操作・表示** — メニューと戦闘画面を画面幅に合わせて組み替え、ストーリー、無限天守、ランク戦などを異なる色と画像アイコンで見分けられるようにしました。小型画面に合わせた表紙画像を追加しました。
- **映像・音声** — 戦士の足元の影をまとめて描画します。既存ボイスの音量・優先度・重なりを調整し、Opusを再生できないブラウザー向けにMP3を追加しました。BGMは選んだ曲だけを読み込みます。ブラウザーが初回の自動再生を制限している場合は、画面を操作すると再生します。
- **検索向け情報** — ストーリーⅡ、探索フィールド、カメラと操作の案内をHTMLに追加し、検索結果・共有用の説明、構造化データ、画像サイトマップを更新しました。

無限天守の参考 [コーエーテクモ『戦国無双４-II』無限城（本館）](https://www.gamecity.ne.jp/sengoku4/2/mode.html)。

探索フィールドの参考 [バンダイナムコ『テイルズ オブ デスティニー2』製品紹介](https://www.bandainamcoent.co.jp/cs/list/talesofdestiny2/product/index.html)。
