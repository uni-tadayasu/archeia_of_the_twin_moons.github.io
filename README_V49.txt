【変更内容】
・V47の強制「1行表示＋はみ出し切り捨て・省略記号」を停止し、V49の全文可読レイアウトへ変更。
・短いラベル／ボタン／キャラ名は可能ならフォントサイズを動的に調整。収まらない場合は文字を切らずに自然に改行。
・長い技名、キャラ説明、ストーリー本文、メニュー文字、商店説明を欠けずに表示。
・画像、キャラクター肖像は縦横比を維持し、カード内に収まる表示へ調整。
・スマホ縦横、低い横画面、タブレット、PCの各幅でグリッド列数、上下のスクロール、余白を自動調整。
・HUD、技名／奥義カットイン、フィールド情報、アドベンチャー等のポップアップとモーダルの表示制限を調整。
・V45の自由配置可能なスマホ操作ボタンの位置データは変更しない。
・ゲーム本体の戦闘コード、モデル、Motion、音楽、サーバー用Workerは変更しない。

【導入方法】
1. 現在のゲーム全データをバックアップします。
2. このZIPを解凍し、同じ相対パスで4つのファイルを上書きします。
3. GitHub Pagesにアップロード（または既存の同期フォルダへ反映）します。
4. Chromeなら Ctrl + Shift + R でキャッシュを再読み込みします。
5. PC、スマホ縦画面・横画面、設定、商店、戦闘画面を確認します。
