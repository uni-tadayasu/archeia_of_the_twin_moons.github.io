# 双月のアルケイア Riftfall Arena V55.29

## 更新内容

- 藤原信頼の通常攻撃「呪印」で、呪印が付いた相手の頭上に透過CGのドクロが現れます。ドクロは相手に追従し、呪印の終了・撃破・退場で消えます。
- 奥義の名前は **呪いの剣** です。暗転、連続する雷撃、巨大な剣の落下、着弾の光を新規CGと2D画像のアニメーションで表現しました。参照したのは『テイルズ オブ デスティニー2』の「インディグネイト・ジャッジメント」です。雷撃は演出で、従来の奥義と同じ単発のダメージ・HP吸収が着弾時に発生します。
- 秘奥義「十拳剣」は金色の専用CGに置き換えました。鬼火、呪いの光、呪いの陣、拘束の鎖も画像ベースの演出で表示します。
- ランク戦は既存の対戦バランスで動作し、通常攻撃の命中通知を受けた相手にドクロを表示します。ランク戦のドクロは演出です。

## 適用方法

1. V55.28適用済みのサイトに、ZIP内のクライアント更新ファイルをフォルダー階層ごと上書きします。上書き先は `index.html` があるフォルダーです。
2. ランク戦の命中時にもドクロを表示する場合は、`server/worker.js` と `server/ranked-rules.js` を既存のWorkerのソースへ反映して、いつもの手順で再デプロイしてください。旧Workerと組み合わせた場合、ランク戦でのドクロ判定だけが省略されます。
3. メニューのバージョン表示が **V55.29** になったことを確認します。

演出の参考 [テイルズオブ用語辞典の技解説](https://w.atwiki.jp/talesofdic/pages/1378.html)。
