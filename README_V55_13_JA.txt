Riftfall Arena V55.13 — 実空間戦闘・ストーリー室内・CGワールド導入版
作成日：2026-11-12
対象：双月のアルケイア / Riftfall Arena
正式URL：https://www.kasai-solutions-inc.com/

【導入内容】
1. 戦闘ステージを実空間化
  従来の円形闘技場の上に、CG背景と一体化する3D床・側壁・柱・梁・照明を描画します。
  CG画像の前にキャラを並べるだけではなく、Three.jsシーンへ舞台装置を追加します。
  既存の攻撃判定は残しているため、部屋の見た目が戦闘エリアより大きくても、
  見えない戦闘境界自体は以前のままです。

2. ストーリーモードの建物侵入
  既存の城下町・町フィールドに、入れる建物を最大4軒追加します。
  近づいてJキー／斬る操作で室内へ移動し、キャラの元モデルで探索できます。
  3Dの部屋に床・壁・柱・梁・照明・家具を配置。
  仕掛けのレバー→隠し扉→宝箱→出口、というギミックを追加しています。
  宝箱の報酬は同一章・同一建物につき1回のみ端末に記録します。

3. ダンジョン・ワールドのCG強化
  既存の自動生成迷宮へ梁・上部装飾・祭壇台座を追加し、
  洞窟・神殿・城内のCG背景と実際の3D建築物を併用します。
  既存の迷路構造・敵シンボル・ボス戦・マップ進行は維持します。

4. 無限天守
  HP持ち越し・無限階層・ランキングは維持します。
  和風／洋風テーマに従い、城内の柱・壁・床などをThree.jsの戦闘シーンに表示します。
  過去のCG背景は引き続き使い、進軍している感覚を強化します。
  商用作品のマップや画像を転載したものではありません。

5. GitHub独自ドメイン
  GitHub CNAMEの www.kasai-solutions-inc.com を確認しました。
  canonical / og:url / og:image / Twitter共有URLを新しい正式ドメインに統一。
  CSS・JSの読み込みは相対パスで、カスタムドメイン直下でも参照できる構成です。

【重要な制限】
・ゲーム内のすべての建物に入れるわけではなく、第一段階では最大4軒です。
・外見をCG化しても内部の3Dはポリゴンで描画されます。
・円形の戦闘判定は変更していません。視覚的には四角い広間に見せる方式です。
・オンライン4人協力、実機スマホ、GitHub Pages本番での完全な動作検証は未実施。
・Cloudflare Workersの変更は不要です。
・GitHub連携の書き込み権限がない場合、GitHubへの反映は手動で行ってください。
