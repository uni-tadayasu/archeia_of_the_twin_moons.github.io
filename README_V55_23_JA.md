# Riftfall Arena V55.23 更新手順

V55.22を適用済みのフォルダーを使います。ZIPを展開し、`index.html` がある階層に中身を重ねてください。`assets/` と `server/` の階層を保ちます。

オンラインで天子を使う際は、添付の `worker(3).js` を基に統合した `server/worker.js` を、既存のCloudflare Workerに反映します。ダッシュボードで置き換える場合も、使うソースはこの単体ファイルです。V55.22で設定した `RANK_HUB` と `RANK_DUEL` を含め、使用中のバインディング、秘密変数、ドメインとCORSの設定を引き継ぎます。V55.23で追加するマイグレーションはありません。Workerを反映した後、静的ファイルを通常の手順で更新してください。

## 天子

神属性の戦士です。運営長認証後、各モードの戦士選択に表示されます。オンラインでは運営長認証とセーブ同期が必要です。拠点所有者が運営長として認証済みの場合は、攻城戦の城主・防衛ボスに設定できます。

添付の `tenshi.glb` をそのまま同梱しています。ゲーム起動時に必要なシーンで24関節の骨格と18種類のモーションを設定し、元の形状、燕尾服、材質とテクスチャを使います。モーションは待機、歩き、走り、防御、跳躍と着地、三段攻撃、踏み込み、詠唱、術の発動、奥義、秘奥義、被弾、ダウン、勝利です。

通常ルールでは日輪連掌、暁光の矢、星踏み、神紋・星環、月弧の返し、晨光の祈り、皇天・暁界、双月神楽・天照を使います。入力表は人物・技ガイドの `tenshi.html` にあります。ランクマッチは既存の対戦専用バランスを適用し、天子のモデル・モーション・神属性の演出を使います。

## サイトと検証

藍、朱、翡翠を使ったトップとモード案内、天儀台・闘技場・水辺のCG背景、元モデルから描画した立ち絵を追加しました。スマホではトップの画像を表示幅に合わせて配信します。ゲーム内の闘技場と竹林にも新しい背景を使用しています。

ゲーム、操作ガイド、舞台ガイド、人物・技ガイドに正規URL、ページ説明、共有画像を設定し、構造化データ、ページ間リンク、画像付きサイトマップを更新しました。公開時の正規URLは既存設定の `https://www.kasai-solutions-inc.com/` です。

検証の範囲と結果は `QA_V55_23.txt` に記載しました。
