Riftfall Arena V50 城・攻城戦

和風/洋風拠点・城Lv1～100・Lv10ごとにダンジョン1階層追加し外観豪華化。各階層のHP・攻撃力・防御力が段階的に上昇。開始時に「続きから／最初から」とバックアップ復元、購入・強化・寄付等の重要操作の確認画面を追加。領主撃破で勝利し敵の灯晶10%獲得。攻撃者と防衛者にシステムメール。サーバーが勝敗と報酬を判定。

変更6ファイルをゲームへ上書き。server/worker.jsはCloudflare Workersへデプロイ。

第1版のダンジョンは操作パネル式の階層バトルであり、3D歩行型ではありません。本番前にアカウント2つでテストしてください。
