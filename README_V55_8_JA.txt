## 適用手順
1. 既存GitHubリポジトリ全体をバックアップする。
2. 解凍したZIP内のファイル・フォルダーを **同じ相対パス** で GitHub へ上書き／追加する。
3. GitHub Pagesの公開を待ち、Chromeの場合 Ctrl+Shift+R、スマホはサイトを閉じて開き直す。
4. キャラクター選択→「ロウエン」「ミナセ」「ガロウ」など一般モデルで、衣服・肌が正しい色と位置に表示されるか確認する。
5. 最後に戦闘・4人協力・無限天守・攻城戦・スマホのタッチ操作を実機で確認する。
