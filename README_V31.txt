Riftfall Arena V31 — 運営長専用「キャラクター編集・テンプレート＆全ランダム生成」

追加機能
- テンプレート6階級：一般／雑魚敵／小ボス／中ボス／大ボス／ラスボス
- テンプレートを選択したあと、「基本情報・能力・技魔法を全ランダム生成」で名前・肩書き・属性・HP・速度・攻防・技名・種類・演出・威力まで一括生成
- ランダム生成はプレビューのみ。保存前の確認UIを通過し、運営長本人の署名トークンでWorkerへ保存すると公開
- 通常技スロット数を1～24へ変更。固定／順番（技A・Bで順送り）を選択
- 技スロット選択パネルを戦闘画面に実装。全スロットから個別に使用できる
- 技種類・属性・CG演出・色・数値・連撃・範囲・詠唱・追加効果などを編集。奥義・秘奥義も同様
- GLB、画像、BGM、運営・運営長の使用権限は変更しません

使い方
1 このHTMLをChromeで開き、現在のゲームZIP（V28以降導入済み）を選択
2 「更新ファイルのみZIP生成」で差分ZIPを保存
3 GitHub Pagesへ出力ZIPの中身を同じ階層へアップロード
4 server/worker.js をCloudflare Workerに再デプロイ
5 Ctrl+Shift+Rで再読み込み。運営長でログインしてキャラクター編集を開く
6 テンプレート選択 → ランダム生成 → 手動調整 → 確認UI → 保存

注意
- 階級テンプレートは能力値の目安であり、敵出現のロールやストーリー上のボス設定は自動変更しません
- 固有技を別の技種類に変更すると、固有の特殊な演出・スクリプトと一致しない場合があります
- 新しいCG画像そのものを生成する機能ではありません。ゲームの既存描画エンジンにある演出を使います
- 初回の導入ではブラウザとWorker両方の更新が必要です
