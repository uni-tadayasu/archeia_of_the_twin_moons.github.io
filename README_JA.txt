Riftfall Arena / 双月のアルケイア — 戦闘開始・タイトル戻り対策 V9.1

対象：あなたの最新ゲームZIP（例: archeia_of_the_twin_moons.github.io-main(5).zip）
このセットは「完成したゲーム全体」ではなく「更新ファイルだけ」を生成するパッチツールです。
大容量モデル、BGM、保存データ、運営権限、魔王V8の技は変更しません。

修正内容:
・CPU対戦/イベント/2対2で、確定した出場キャラだけのGLBを準備
・物語の敵/味方モデルだけを読み込み、開始時の全モデル読込を廃止
・探索用モデルの同時読み込みを抑制（NPC会話やイベントは維持）
・オンライン対戦/決闘/運営乱入/アドベンチャーの準備中例外の扱いを強化
・スマホの初期描画解像度を1.0以下に抑え、影マップをオフ（PCは従来通り）
・同期処理による戦闘準備中のページ再読み込みを防ぐ
・エラーを画面上に表示し、次回起動時に前回の異常終了の手掛かりを提示
・魔王の孵化モデルの描画は変更せず、ゼルグリムの事前生成を空き時間へ移す

【使用方法】
1. このZIPを展開し、riftfall_battle_v9_builder.html をWindows Chromeで開く。
2. 「現在のゲーム全体ZIP」を選択する。
3. 「更新ファイルだけを生成」を押す。
4. ダウンロードした『Riftfall_BattleFix_V9_1_ChangedOnly.zip』を展開し、
   中のファイルをGitHubリポジトリの同名の場所へ上書きする。
   サーバー worker.js、GLB、音楽は更新不要。
5. GitHub Pagesの反映後、スマホでタブを閉じて開き直し、読み込みを更新する。

変更予定: main.js / index.html / maou-abilities.js / gaizorg-adventure.js / battle-crash-diagnostics.js
元ZIPの構成が一致しない場合にはZIP生成せず、エラーを表示して安全に停止します。

注意:
・ゲームのモデル読み込みやGPUドライバーのメモリ不足を完全に防げる保証はありません。
・実機での動作は未検証です。異常終了後に診断ログが表示されたらコピーして共有してください。
・作業前に現在のGitHubファイルのバックアップを残してください。
