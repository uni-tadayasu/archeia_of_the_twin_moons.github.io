Riftfall Arena / BGM二重再生 + 一般キャラ2.0倍 V10.1

【目的】
- BGMを同時に最大1曲に制限。すばやく切り替えても旧曲が残らない。
- 運営・運営長以外の一般プレイヤーが使えるキャラクターを元サイズの2.0倍に変更。
- モデル本体GLB、BGM MP3、技、ステータス、保存データ、Cloudflare Workerは変更なし。

【倍率の重要事項】
V9.2(1.3倍)が導入済みの時には「1.3→2.0」に置換します。
1.3×2=2.6倍にはなりません。
V9.2未導入の場合は一般用の定義にちょうど2倍を追加します。
各ゲームモードは同じ data.js の height 定義を参照します。

【BGM】
旧曲を必ず停止してから新曲を再生。
同じ音源のメニュー/物語、ボス/イベントは同じプレーヤーを共有。
重複防止のためクロスフェード演出は廃止（切替時は即切替）。
ヴァルガルドBGM、アドベンチャーBGM、音量、ミュート、BGM優先度は維持します。

【使い方: おすすめ】
1. WindowsでゲームZIPを解凍します。
2. Riftfall_BGM_Scale_V10_1_Updater.html をChromeで開きます。
3. ルート直下の index.html、main.js、data.js の3ファイルを指定します。
4. 「更新ファイルのみのZIPを生成」を押します。
5. 生成されたZIPを解凍し、GitHubの同名ファイルだけ上書きしてください。
6. GitHub Pagesのデプロイ完了後に Ctrl+Shift+R で強制再読み込みしてください。

現在のデータにすでにBGM修正V10が入っている場合は二重適用しません。
出力に含まれるのは変更があったファイルと説明書だけです。

【テスト】
修正ツールの動作、JavaScript構文と差分ZIPの整合性、一般用倍率の確認を実施。
実際の端末でのBGM切替・全モードの描画は未検証です。
