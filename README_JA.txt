Riftfall Arena 魔王技構成 V8 （更新ファイルのみ）
================================================
更新ファイル: maou-abilities.js 1ファイルのみ

■ 最終技構成
通常技は3種類のみ:
  1. 滅界眼光《スカーレット・アポカリプス》: 前方扇形の赤い眼光レーザー
  2. 口卵術《翠影孵化》: 卵1個→魔卵獣ゼルグリム1体（耐久3回・HP非表示）
  3. 無尽光輪《全生命復元》: HP完全回復（回復ボタン）
奥義: 終極螺旋穿光《アストラル・ピアサー》
     白金と紫の二重螺旋の貫通光線（オリジナル演出）
秘奥義: 命脈簒奪《エクリプス・ドレイン》
       半径11.5以内の敵からHPを吸収し、自身を回復

■ 特殊能力（維持）
- 虹光・金剛態: 被ダメージ半減・ひるみ無効、30秒
- 雷光再生陣: 30秒間継続回復、クールダウンなし
- 魔王再誕: HP0になるたび、50%で完全復活（回数制限なし）
  ※同じ戦闘不能状態で繰り返し抽選はしません。失敗した場合は通常どおり倒れます。

■ 更新手順
1. V7.4を導入済みのゲーム（または同等の現行版）のGitHubルートにある
   maou-abilities.js を、本ZIP内の同名ファイルで上書き。
2. GitHub Pagesのデプロイを待ち、ブラウザキャッシュを更新（Ctrl+Shift+R）。
3. server/worker.js、画像、音楽、GLBは今回変更不要です。

■ 注意
- この変更は maou-abilities.js が取り込んだ data.js の技設定を
  実行時に更新する方法です。data.js/Worker内の元の技一覧の記述自体は
  残っていますが、通常モードのゲームプレイで使う技構成は上記に更新されます。
- オンライン同期では対戦相手側にも最新版のコードが必要です。
- スマホ実機での安定性やネットワークでのダメージ上限は未検証です。
- 元の魔王モデル、モーション、ゼルグリム召喚安全対策は変更しません。
